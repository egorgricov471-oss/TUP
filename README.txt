ТУП — оновлення дизайну та функцій

1. У Supabase SQL Editor виконай SUPABASE_MIGRATION_V2.sql.
   Це додає поле date_type до dates, переносить старі типи з is_death і не видаляє записи.

2. Завантаж у корінь GitHub-репозиторію файли index.html, style.css, app.js, admin.html, admin.js.
   Замінити старі однойменні файли. Не завантажуй папку TUP-fixed як вкладену папку.

3. Додай ДВА окремі зображення в корінь репозиторію (поруч з index.html):
   - group-photo-blurred.jpg — фото групи, на якому ти сам заздалегідь розмиєш потрібних людей. Сайт не додає розмиття автоматично. Це зображення показується гостям.
   - group-logo.jpg — оригінальне чітке фото/логотип для учасників після входу.
   Файли мають бути саме з такими назвами. Можна використовувати JPG.

4. Зроби commit/push. Vercel має автоматично задеплоїти зміни.

Примітки:
- Коментарі використовують наявну таблицю public.comments і її RLS-політики.
- Для написання коментарів користувач має бути схвалений (approved) або admin.
- Таймер відраховує час до найближчого майбутнього запису в таблиці events.
- Список дат сортується за наступним наближенням дати; спочатку показує 10 записів.
